# Random Quote Generator 💬

One quote, right on time — 44 hand-picked quotes on motivation, wisdom, success, life, humor, and love.

## Features

- **44 quotes** bundled in `js/data.js` across 6 categories: Motivation, Wisdom, Success, Life, Humor, Love.
- **New quote button** — or press `Space`. The generator never repeats the same quote twice in a row.
- **Category filter** — pick a mood and quotes come only from that category.
- **Copy button** — copies the quote with its author in one tap.
- **Share link** — opens an X/Twitter intent with the quote pre-filled, ready to post.

## Run locally

No build step, no dependencies — just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Deploy

Deploy anywhere that serves static files (GitHub Pages, Netlify, Vercel…). Upload the whole folder as-is.

## Tech

Pure HTML, CSS, and vanilla JavaScript. Google Fonts only (Bricolage Grotesque, Inter, JetBrains Mono).
